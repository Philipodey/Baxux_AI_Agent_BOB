# Bob: The AI Whisky Recommender 🥃

Bob is an AI agent that analyzes your virtual whisky bar on BAXUS and recommends new bottles based on your preferences.

## 🔧 How It Works
- Analyzes your current collection (proof, price, spirit type, etc.)
- Suggests similar or complementary bottles from a dataset of 500+
- Returns results with personalized reasoning
